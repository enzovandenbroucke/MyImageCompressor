# Image attribution

The photographic example in `photo-0809.png` and `photo-0809-detail.png` derives
from validation image `0809.png` in the DIV2K dataset. It illustrates the
research codec's actual output. The original photograph and reconstructed
variants remain subject to the original image owner's rights and the dataset's
terms; no software license for this repository grants rights to these photos.

The [official dataset page](https://data.vision.ee.ethz.ch/cvl/DIV2K/) makes the
dataset available for academic research and states that copyright belongs to
the original image owners. It does not identify the individual photographer
of `0809.png`.

Dataset references requested by the authors:

- Eirikur Agustsson and Radu Timofte, *NTIRE 2017 Challenge on Single Image
  Super-Resolution: Dataset and Study*, CVPR Workshops, 2017.
- Radu Timofte et al., *NTIRE 2017 Challenge on Single Image Super-Resolution:
  Methods and Results*, CVPR Workshops, 2017.

The photograph is encoded at its original resolution. The overview is resized
only for documentation, and the marked crop is enlarged with nearest-neighbor
sampling. Display adjustments do not enter the recorded full-image metrics.
The source hash and crop coordinates are recorded in
`benchmarks/photo-0809.json`.

`comparison.png` is a separate, original synthetic illustration generated by
`scripts/make_demo.py` and contains no dataset photographs.
